# Port Status Checker

## Project Description
A Python-based network utility that checks the status of TCP ports on a target host using socket programming.

## Features
- Accepts target IP address.
- Accepts starting and ending port numbers.
- Checks TCP connections.
- Displays port status as Open, Closed, or Filtered.

## Technologies Used
- Python
- Socket Programming

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run `python port_checker.py`.
4. Enter the target IP address and port range.
